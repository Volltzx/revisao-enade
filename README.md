# Revisão ENADE 2026 — Ciência da Computação

Plataforma de estudo para o ENADE (29/11/2026): cronograma de revisão, trilhas em linguagem simples para 37 disciplinas de computação e 389 questões de múltipla escolha em três níveis de dificuldade, cada uma com o passo a passo de como chegar à resposta, simulado e revisão de erros.

Acesse: https://volltzx.github.io/revisao-enade/

É um único arquivo `index.html`, sem dependências. O progresso fica salvo no navegador de cada pessoa (localStorage).
